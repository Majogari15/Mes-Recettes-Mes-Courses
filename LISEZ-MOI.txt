====================================================
  MES RECETTES, MES COURSES — Guide d'utilisation (.exe)
====================================================

Cette version inclut Python et les modules nécessaires à l'application.
Double-cliquez sur MesRecettes.exe pour la lancer. L'import depuis une
photo nécessite toutefois Tesseract OCR installé séparément (section 2).

Au tout premier lancement, une fenêtre affiche une clause de responsabilité
(notamment sur la gestion des allergènes) que vous devez lire et accepter
(case à cocher) pour pouvoir continuer. Cette étape n'apparaît qu'une seule
fois ; votre acceptation est mémorisée automatiquement.


Les archives de développement ne sont pas nécessaires au fonctionnement : elles
sont rangées dans le dossier `docs/history` du dossier source.


--------------------------------------------------
1. FICHIERS À GARDER ENSEMBLE
--------------------------------------------------

Ce dossier contient, à côté de MesRecettes.exe, plusieurs fichiers
indispensables à son bon fonctionnement :

  - i18n_desktop.json
      Tous les textes de l'interface dans les 4 langues (français,
      anglais, espagnol, allemand). Sans lui, l'application démarre
      quand même (un petit noyau français minimal de secours est prévu
      pour ça), mais la plupart des textes et les 3 langues autres que
      le français ne s'afficheront pas correctement.

  - ingredients_par_defaut.json
      Liste d'1030 ingrédients de cuisine courants, utilisée pour
      pré-remplir vos listes déroulantes au premier lancement.

  - valeurs_nutritionnelles.json
      Base de valeurs nutritionnelles estimées (calories, protéines,
      glucides, lipides) pour ces 1030 ingrédients, utilisée pour
      l'estimation nutritionnelle de vos recettes.

  - ingredient_allergenes.json
      Base des allergènes présents dans ces 1030 ingrédients, utilisée
      pour la détection automatique des allergènes dans vos recettes.

  - ingredient_substitutions.json
      Base d'une trentaine de substitutions culinaires courantes (beurre,
      oeufs, farine, lait...), utilisée pour "Gérer les substitutions".

  - ingredient_translations_en.json / ingredient_translations_es.json /
    ingredient_translations_de.json
      Traduction anglaise / espagnole / allemande des 1030 ingrédients
      courants, utilisée pour l'affichage multilingue (voir section 3
      ci-dessous).

  - ingredient_substitutions_en.json / ingredient_substitutions_es.json /
    ingredient_substitutions_de.json
      Traduction anglaise / espagnole / allemande de la base de
      substitutions ci-dessus.

  - flag_fr.png / flag_uk.png / flag_es.png / flag_de.png
      Icônes de drapeaux pour le menu déroulant de langue.

  - LISEZ-MOI.txt
      Ce fichier.

>>> IMPORTANT : ne déplacez JAMAIS MesRecettes.exe tout seul. Déplacez
>>> toujours le dossier ENTIER (avec tous ces fichiers dedans), sur une clé
>>> USB, un autre PC, ou ailleurs sur votre disque. Sans ces fichiers juste
>>> à côté de l'exécutable, certaines fonctionnalités ne pourront pas
>>> charger leurs données au démarrage.

Au fur et à mesure de votre utilisation, l'application créera
automatiquement d'autres fichiers et dossiers pour vos données personnelles.
Ils sont placés à côté de l'exécutable si ce dossier est accessible en
écriture ; sinon, l'application utilise le dossier du profil utilisateur
%LocalAppData%\MesRecettesMesCourses\. L'écran Diagnostic permet de voir
et d'ouvrir le dossier effectivement utilisé :

  recipes.json            vos recettes
  ingredients.json        votre liste d'ingrédients personnelle
  ingredient_prices.json  les prix que vous aurez renseignés (facultatif)
  ingredient_custom_data.json  vos modifications d'ingrédients (facultatif)
  ingredient_dismissed_pairs.json  doublons d'ingrédients ignorés (facultatif)
  weekly_plan.json        votre planning de la semaine
  weekly_plan_history.json  l'historique de vos anciens plannings (facultatif)
  weekly_plan_templates.json  vos modèles de planning enregistrés (facultatif)
  menus.json              vos menus enregistrés
  saved_shopping_lists.json  vos listes de courses enregistrées (facultatif)
  pantry.json              le contenu de votre garde-manger (facultatif)
  trash.json               la corbeille des recettes supprimées
  recent_views.json       l'historique des recettes récemment consultées
  settings.json            vos préférences (thème, dossier cloud...)
  images/                  les photos de vos recettes et de votre journal
  backups/                 vos sauvegardes automatiques périodiques

Pour sauvegarder ou transférer TOUTES vos données en une fois, utilisez de
préférence le bouton "💾 Importer / Exporter les données" à l'intérieur de
l'application (il crée un fichier .zip unique avec tout ce qu'il faut),
plutôt que de copier chaque fichier à la main.


--------------------------------------------------
2. FONCTIONNALITÉ NÉCESSITANT UN LOGICIEL SUPPLÉMENTAIRE
--------------------------------------------------

Toutes les fonctionnalités de l'application sont incluses dans
MesRecettes.exe, SAUF une : l'import de recette depuis une PHOTO
(reconnaissance de texte / OCR).

Cette fonctionnalité s'appuie sur un programme externe appelé
Tesseract OCR, qui doit être installé séparément sur votre PC (ce n'est
pas inclus dans l'exécutable, et ce n'est pas un simple programme Python) :

  Windows : téléchargez l'installateur depuis
            https://github.com/UB-Mannheim/tesseract/wiki
            (cochez la langue française si elle est proposée),
            installez-le, puis redémarrez MesRecettes.exe.

Sans Tesseract OCR installé, le bouton "📷 Importer une recette depuis une
photo" reste accessible mais vous indiquera clairement ce qu'il manque
plutôt que de planter. Toutes les autres fonctionnalités (y compris
l'import de recette depuis un LIEN internet) n'ont besoin de rien de plus.

L'import photo peut traiter plusieurs pages dans l'ordre, corriger leur
orientation, découper les fiches de préparation en grille et préremplir le
titre, les portions, les ingrédients et les étapes. Relisez toujours le
résultat : une fraction ou un caractère peut encore être mal reconnu.


--------------------------------------------------
3. CHANGER DE LANGUE
--------------------------------------------------

Un menu déroulant en haut à droite de la page d'accueil (et de l'écran de
clause de responsabilité au tout premier lancement) permet de choisir
entre français, anglais, espagnol et allemand. Toute l'interface bascule
immédiatement, y compris les 1030 ingrédients courants, les rayons de
courses, les catégories, les difficultés, les allergènes, les jours de
la semaine et créneaux de repas, les options de tri des recettes, les
unités de mesure (pièce, cuillère à soupe/café...) et les substituts
suggérés. Vos propres recettes (noms, descriptions, notes) ne sont
jamais traduites automatiquement, et vos données restent toujours
enregistrées en français en interne, quelle que soit la langue affichée.

Au tout premier lancement, l'application démarre dans la langue de votre
système si elle est reconnue (français, anglais, espagnol ou allemand) ; vous
pouvez la changer à tout moment.


--------------------------------------------------
4. APERÇU DES FONCTIONNALITÉS
--------------------------------------------------

- Ajouter, modifier, dupliquer, supprimer des recettes (avec plusieurs
  photos, description, notes personnelles, allergènes, catégorie, temps,
  difficulté, favoris, note en étoiles), avec alerte si un même ingrédient
  se retrouve sur plusieurs lignes par erreur
- Importer une recette depuis un lien internet ou depuis une photo
- Liste de courses construite recette par recette (bouton "Ajouter aux
  courses"), modifiable ligne par ligne (quantité, suppression), avec
  possibilité d'ajouter des articles qui ne viennent d'aucune recette, et
  d'enregistrer/recharger une liste pour plus tard — regroupée par rayon de
  magasin, avec un mode "cocher au fur et à mesure"
- Recherche par ingrédient (quelles recettes utilisent tel ingrédient ?),
  avec ouverture directe de la recette trouvée
- Comparer deux ou trois recettes côte à côte
- Filtre "je veux / je ne veux pas" certains ingrédients
- Filtres rapides sur la page d'accueil (favoris, recettes rapides,
  végétarien, liste d'envies)
- Liste d'envies (recettes repérées mais jamais cuisinées), avec rappel
  automatique sur la page d'accueil après 90 jours d'attente
- "Que puis-je cuisiner ?" à partir de ce que vous avez chez vous, avec
  alerte si vous n'avez pas une quantité suffisante d'un ingrédient, et
  détection des recettes réalisables grâce à un substitut d'ingrédient
- Substituts d'ingrédients suggérés (beurre, oeufs, farine...), personnalisables
- Suivi du garde-manger avec quantités, décompté automatiquement (sur
  proposition) après avoir cuisiné une recette
- Planning de la semaine en vue calendrier (jours toujours visibles même en
  faisant défiler), avec export vers un calendrier (.ics) qui se répète
  automatiquement chaque semaine
- Mes menus (combinaisons de plusieurs recettes)
- Mode cuisine plein écran et minuteurs multiples réglables (avec alarme
  sonore et clignotante)
- QR code de recette compatible avec l'application mobile dans les deux sens
  (export bureau → mobile et import de QR mobile depuis une image)
- Journal de cuisine (notes et photos à chaque fois que vous cuisinez)
- Coût et valeurs nutritionnelles estimés par recette
- Statistiques (recettes les plus cuisinées, coût moyen, calories
  moyennes, graphique d'évolution mensuelle...)
- Corbeille (récupérer une recette supprimée par erreur)
- Sauvegardes automatiques périodiques, avec copie optionnelle vers un
  dossier cloud (Google Drive, OneDrive, Dropbox...)
- Thème clair / sombre, au choix
- Interface disponible en français, anglais, espagnol et allemand (voir section 3)
- Export d'un livre de recettes complet en PDF, avec pages numérotées et
  numéro de page indiqué dans le sommaire

Un bouton "☕ Faire un don" en haut à gauche de la page d'accueil ouvre la
page https://buymeacoffee.com/majogari dans votre navigateur, si vous
souhaitez soutenir le développement de l'application (entièrement
facultatif, bien sûr).

Pour le détail complet de chaque fonctionnalité, consultez le document
LISEZ-MOI.md fourni avec le code source (destiné aux utilisateurs Python),
ou explorez simplement l'application : chaque écran est accompagné de
petites explications.


--------------------------------------------------
5. PROBLÈME AU LANCEMENT ?
--------------------------------------------------

- "Windows a protégé votre ordinateur" (SmartScreen) : vérifiez la
  provenance du fichier avant de poursuivre. Ce message ne permet pas,
  à lui seul, de conclure que le fichier est sûr ou dangereux.

- Une fonctionnalité indique qu'un fichier manque, ou le contenu d'une
  autre langue que le français ne s'affiche pas : vérifiez que tous les
  fichiers .json et .png listés en section 1 sont bien présents à côté de
  MesRecettes.exe.

- Rien ne se passe en double-cliquant : essayez de lancer l'exécutable
  depuis une invite de commandes (cmd) pour voir si un message d'erreur
  s'affiche, et vérifiez qu'aucun antivirus ne bloque le fichier.

Bon appétit !


--------------------------------------------------
6. IMPRESSION WINDOWS
--------------------------------------------------

Le bouton Imprimer ouvre la boîte d’imprimante Windows et transmet le PDF au
pilote choisi, sans dépendre de la commande d’impression de votre lecteur PDF.
La construction .exe inclut le moteur de rendu nécessaire. Avec main.pyw,
exécutez python -m pip install -r requirements.txt. Si le pilote refuse le
travail, l’application conserve le PDF et vous propose de l’ouvrir
manuellement après confirmation.

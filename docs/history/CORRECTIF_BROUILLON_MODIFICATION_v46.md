# Brouillon conservé lors des modifications — build 46

Lorsqu'une recette existante est ouverte avec « Modifier », son brouillon est maintenant conservé après chaque enregistrement, y compris lorsque l'utilisateur n'a changé aucun champ.

Avant de fermer la fenêtre après un enregistrement réussi, l'application réécrit le brouillon avec les valeurs actuelles. La prochaine ouverture propose donc toujours de récupérer ce dernier état. L'utilisateur peut choisir « Non » dans la fenêtre de récupération pour supprimer le brouillon.

Les nouvelles recettes gardent le comportement précédent : leur brouillon disparaît après la création réussie.

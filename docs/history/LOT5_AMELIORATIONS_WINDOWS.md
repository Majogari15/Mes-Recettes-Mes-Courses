# Lot 5 — Historique, statistiques et confort Windows (v8)

- Journal de cuisine enrichi : note 1 à 5 à chaque cuisson, moyenne du journal, photos et notes conservées.
- Comparaison étendue à trois recettes, avec repérage des meilleures valeurs pour plusieurs critères.
- Statistiques exportables en CSV et ajout du temps total moyen.
- Collage direct d'une image dans l'onglet Photos avec Ctrl+V (quand le focus n'est pas dans un champ texte).
- Raccourci Ctrl+S dans le formulaire de recette.
- Compatibilité ascendante : les anciens journaux sans note restent lisibles.

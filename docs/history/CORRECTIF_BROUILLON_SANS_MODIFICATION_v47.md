# Brouillon uniquement après modification — build 47

L'ouverture d'une recette dans « Modifier » mémorise désormais son état initial. Le brouillon est supprimé si la recette est annulée ou enregistrée sans changement ; la fenêtre de récupération ne s'affiche donc pas lors d'une simple consultation.

Dès qu'un champ est réellement modifié, le brouillon est conservé et mis à jour automatiquement. Il pourra être récupéré à la prochaine ouverture.
